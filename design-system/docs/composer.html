3. Коли вживати

Пояс стоїть на всіх екранах чату й тримається внизу над клавіатурою. Плейсхолдер — «Повідомлення», кнопка — «Надіслати» (словник дій). Перше повідомлення людина пише сама: порожній стан підказує «Представся й запитай, чи кімната ще вільна…».

«Надіслати» коралова, лише коли в полі є текст. Якщо поле порожнє, розмова вантажиться чи не завантажилась, кнопка має disabled і прозорість 0.4. На chat-error коралова дія одна — «Спробувати ще» (правка уроку 7, The One Coral Button Rule).

Джерела: DESIGN.md → Components → Buttons (Send), Inputs / Fields, Правки уроку 7 і 8; microcopy.md → Чат (C-15…C-17, C-23, C-29); ui/inventory.md → Чат

4. Правило і антиправило

5. Стани

Поле — як .input; кнопка «Надіслати» — як головна дія. Порожнє поле вимикає кнопку: прозорість, без курсора.

Світла тема

Темна тема

Правила для всіх компонентів такі. Наведення й натискання міняють лише фон, колір або рамку. Фон кнопки, чипа, «Надіслати», шапки й капсули меню проступає шаром за --dur-fast (розділ «Рух»). Фокус з клавіатури — кільце --color-focus (AA в обох темах).

Вимкнене — --opacity-disabled і без курсора. Кнопку й поле вимикає атрибут disabled (поза Tab). Вимкнене посилання — без href з aria-disabled="true".

6. Рух

Рух живе в компоненті, а не на екрані: що тут, те й на кожному екрані. Анімуються лише transform і opacity, лише через ролі --dur-* / --ease-* / --move-*; фокус і колір — миттєво. З prefers-reduced-motion: reduce рух вимкнено, кінцевий стан той самий.
