2. Варіанти й розміри

Чотири поєднання верху й низу, що стоять на 16 екранах.

3. Коли вживати

Кожен новий екран починається з оболонки: копіюєш ui/shell.html і заповнюєш .shell__main. Mobile-first, базовий viewport 390×844, одна колонка, бокові поля 16, горизонтального скролу сторінки немає.

Нижній пояс — там, де великий палець. Стрічка має нижнє меню (людина переходить між розділами), оголошення й профіль — панель з однією кораловою дією «Написати Ірині», чат — поле повідомлення. Усі пояси враховують safe-area-inset-bottom. Оголошення починається з фото на всю ширину, яке заходить під статус-бар, — для цього --photo-top знімає верхнє поле.

Джерела: DESIGN.md → Layout; ui/shell.html; ui/inventory.md → Навігація

4. Правило і антиправило

5. Стани

Компонент не інтерактивний — наведення, натискання й фокусу не має. Завантаження показано у варіантах (скелет), вимкненого стану немає.

Правила для всіх: наведення й натискання міняють лише фон, колір або рамку; фокус з клавіатури — кільце --color-focus (AA в обох темах); вимкнене — --opacity-disabled і без курсора; кнопка й поле — атрибут disabled (поза Tab), посилання — без href з aria-disabled="true".
