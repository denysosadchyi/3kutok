Живий компонент із системи. Наведи на рядок легенди — частина обведеться пунктиром.

    18:27

  3. Так, домовилися. Напишу адресу в суботу зранку.

    18:31

3. Коли вживати

Бульбашки складають стрічку на екрані chat — третій крок core loop, прямий контакт. Мої повідомлення праворуч чорнилом, Іринині — ліворуч на сірій поверхні: хто що сказав, видно без підписів. Коралу в стрічці немає — повідомлення не дія (The Coral Means Do).

Текст у бульбашці — рядок користувача (👤 у microcopy.md): «Вітаю! Чи актуальна кімната…» лишається як написано, навіть з окликом. Поки стрічка вантажиться — скелетон із трьох бульбашок.

5. Стани

Компонент не інтерактивний — наведення, натискання й фокусу не має. Завантаження показано у варіантах (скелет), вимкненого стану немає.

Правила для всіх: наведення й натискання міняють лише фон, колір або рамку; фокус з клавіатури — кільце --color-focus (AA в обох темах); вимкнене — --opacity-disabled і без курсора; кнопка й поле — атрибут disabled (поза Tab), посилання — без href з aria-disabled="true".
