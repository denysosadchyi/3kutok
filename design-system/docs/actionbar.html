3. Коли вживати

Панель стоїть на оголошенні й профілі. Контакт у Кутку прямий, без заявок і матчингу, тож на деталях головна дія одна — «Написати Ірині» (D4). Це The One Coral Button Rule у найчистішому вигляді: на екрані одна коралова кнопка, і вона тут.

Поки дані вантажаться, замість кнопки — скелетон тієї ж форми: людина не натисне «Написати» до того, як побачить, кому пише.

Джерела: DESIGN.md → Layout, Named Rules → The One Coral Button; microcopy.md → D4, «Звірка після переписування»

Світла тема

Темна тема

Правила для всіх компонентів такі. Наведення й натискання міняють лише фон, колір або рамку. Фон кнопки, чипа, «Надіслати», шапки й капсули меню проступає шаром за --dur-fast (розділ «Рух»). Фокус з клавіатури — кільце --color-focus (AA в обох темах).

Вимкнене — --opacity-disabled і без курсора. Кнопку й поле вимикає атрибут disabled (поза Tab). Вимкнене посилання — без href з aria-disabled="true".
