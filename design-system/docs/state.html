1. Анатомія

Живий компонент із системи. Наведи на рядок легенди — частина обведеться пунктиром.

За цими умовами оголошень немає

Зміни бюджет, район або дату заїзду.

Змінити фільтри
  1. 1Стан.state — по центру вільного екрана, без підкладки; у помилці — --error і role="alert".
  2. 2Іконка.state__icon — мальована Streamline Freehand 72; у помилці червона.
  3. 3Заголовок.state__title — 19/700, чому так: «За цими умовами оголошень немає».
  4. 4Пояснення.state__text — muted, що можна зробити.
  5. 5Дії.state__actions — одна коралова, друга (якщо є) сіра; у chat-empty кнопки немає.

3. Коли вживати

Стан займає вільне місце між шапкою й нижнім поясом. Заголовок каже, що сталося, пояснення — що робити, кнопка — головна дія: «Змінити фільтри», «Назад до результатів», «Спробувати ще». Помилка завжди звучить однаково: «Не вдалося завантажити {оголошення / профіль / повідомлення}» і «Перевір з’єднання й спробуй ще.»

У порожньому чаті кнопки немає — дія вже є внизу, в полі повідомлення. Якщо дій дві, друга сіра (The One Coral Button Rule). Тон спокійний: без «Ой», окликів і емодзі.

4. Правило і антиправило

5. Стани

Екран стану не інтерактивний; дії в ньому — кнопки з їхніми станами (див. «Кнопка»).

Правила для всіх: наведення й натискання міняють лише фон, колір або рамку; фокус з клавіатури — кільце --color-focus (AA в обох темах); вимкнене — --opacity-disabled і без курсора; кнопка й поле — атрибут disabled (поза Tab), посилання — без href з aria-disabled="true".
