1. Анатомія

Живий компонент із системи. Наведи на рядок легенди — частина обведеться пунктиром.

  1. 1Поле.field — підпис над полем, проміжок 4.
  2. 2Підпис.field__label — 14/500 чорнилом, завжди видимий (не плейсхолдер).
  3. 3Списокselect.input — сіра поверхня, рамка 1 field-edge (3.1:1), висота 48, кути 14.
  4. 4Дата тільки для читанняinput.input[readonly] з inputmode="none" — значення обирають, а не набирають.

2. Варіанти й розміри

Усі варіанти з ui/inventory.md, поруч.

3. Коли вживати

Поля живуть у шторці «Фільтри»: «Район Києва» — список, «Бюджет до, грн/місяць» — число з цифровою клавіатурою, «Дата заїзду» — значення тільки для читання. Підпис завжди над полем і названий так, як людина думає про умову; одиниці — у підписі, не в значенні.

Рамка 1 field-edge тримає 3.1:1 до сірої поверхні — поле читається як поле (правка уроку 7). Під курсором рамка темніє, фокус — зелене кільце.

Джерела: DESIGN.md → Components → Inputs / Fields, Правки уроку 7; microcopy.md → Результати пошуку (шторка фільтрів); ui/inventory.md → Форми

4. Правило і антиправило

5. Стани

Під курсором темнішає рамка; фокус — зелене кільце; вимкнене поле глушиться прозорістю.

Світла тема

Темна тема

Правила для всіх компонентів такі. Наведення й натискання міняють лише фон, колір або рамку. Фон кнопки, чипа, «Надіслати», шапки й капсули меню проступає шаром за --dur-fast (розділ «Рух»). Фокус з клавіатури — кільце --color-focus (AA в обох темах).

Вимкнене — --opacity-disabled і без курсора. Кнопку й поле вимикає атрибут disabled (поза Tab). Вимкнене посилання — без href з aria-disabled="true".
