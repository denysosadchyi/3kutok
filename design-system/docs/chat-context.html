3. Коли вживати

Стоїть першою в стрічці на всіх екранах чату — chat, chat-loading, chat-empty, chat-error. Людина може писати кільком господарям одразу, тож картка відповідає на «про яку кімнату ми говоримо?» без виходу з розмови.

Дані ті самі, що на бирці й в оголошенні: «Кімната біля Лук’янівської», «10 500 грн/міс · з 1 жовтня». Тап веде на оголошення — як «Назад до оголошення» в шапці, але через саму кімнату.

Джерела: DESIGN.md → Components → Чат; microcopy.md → Чат (C-03, C-05, C-06); ui/inventory.md → Чат

5. Стани

Картка кімнати над чатом — посилання: під курсором фон темнішає.

Світла тема

Темна тема

Правила для всіх компонентів такі. Наведення й натискання міняють лише фон, колір або рамку. Фон кнопки, чипа, «Надіслати», шапки й капсули меню проступає шаром за --dur-fast (розділ «Рух»). Фокус з клавіатури — кільце --color-focus (AA в обох темах).

Вимкнене — --opacity-disabled і без курсора. Кнопку й поле вимикає атрибут disabled (поза Tab). Вимкнене посилання — без href з aria-disabled="true".
