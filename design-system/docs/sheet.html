Шторка

Панель знизу для фільтрів: виїжджає поверх стрічки, не відриваючи людину від результатів. Побудована на <details> — працює без JS.

3. Коли вживати

Шторка — для короткого набору умов, які людина змінює, не покидаючи стрічку: район, бюджет, дата заїзду. Тінь «далеко» і затемнення — одне з небагатьох місць, де в системі є глибина: панель справді лежить поверх екрана.

Тексти — «Фільтри · Застосувати фільтри · Змінити фільтри» однаково на всіх listings* (D7); «Скасувати» — текстова кнопка, бо корал-заливка тут одна — «Застосувати».

Джерела: DESIGN.md → Components → Navigation, Elevation; microcopy.md → D7, «Звірка після переписування»

5. Стани

Шторка сама станів не має: їх дають її частини — чип-тригер (див. «Чип»), поля (див. «Поле») і «Скасувати» (див. «Кнопка», text).

Правила для всіх: наведення й натискання міняють лише фон, колір або рамку; фокус з клавіатури — кільце --color-focus (AA в обох темах); вимкнене — --opacity-disabled і без курсора; кнопка й поле — атрибут disabled (поза Tab), посилання — без href з aria-disabled="true".
