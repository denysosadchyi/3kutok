# Components

Перевикористовувані UI-компоненти «Кутка», один файл на компонент.
`index.css` імпортує всі в порядку каскаду; підключати після `../tokens.css`.

- Колір — лише semantic-токени (`--color-*`) з `tokens.css`.
- Геометрія (відступ, радіус, розмір, тінь) — primitive напряму.
- Жодного hex, px чи назви шрифту в класі.
- Розмітка — як у вітрині `ui/kit.html`.
